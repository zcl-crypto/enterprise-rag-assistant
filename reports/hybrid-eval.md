# Dense 与 Hybrid 检索对照

- 时间：2026-09-17T03:42:27.630425+00:00
- 数据：25 份虚构制度，48 个 chunk，110 道问题。
- 方法：相同语料、问题与权限范围；Hybrid 使用本地 BM25（jieba 分词）+ Dense，RRF(k=60) 融合前 20 个候选。
- 环境：本地 CPU + Qdrant local；没有调用生成 API。

- Reranker：`BAAI/bge-reranker-base`，对融合后的前 10 个候选重排。

| 指标 | Dense | Hybrid | Hybrid + Reranker |
| --- | ---: | ---: | ---: |
| Recall@5 | 1.0 | 1.0 | 1.0 |
| 完整支持文档命中@5 | 1 | 1 | 1 |
| MRR | 0.9792 | 0.9938 | 0.9875 |
| 越权文档暴露数 | 0 | 0 | 0 |
| 无答案但返回片段的问题数 | 25 | 25 | 25 |
| 查询延迟 p50 (ms) | 16.42 | 21.77 | 414.38 |
| 查询延迟 p95 (ms) | 20.77 | 26.37 | 453.73 |

这里的无答案指标只衡量召回是否产生候选，不等于回答拒答率。
评估集由本项目虚构语料衍生，规模小且尚未经独立人工复核；结果不能外推到真实企业数据。
未包含生成答案正确率或引用支持率。逐题结果见 `hybrid-eval.json`。

## 证据门控观察

有答案问题 Top-1 重排分最低为 0.50400；无答案问题 Top-1 最高为 0.99757。
两类分数交叠，单一固定阈值无法同时保留所有有答案问题并拒绝所有无答案问题。
Reranker 分数是相关性信号，不是答案受证据支持的证明；本项目尚未实现可靠的自动证据门控。
